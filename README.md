# デザイナー・カリキュラム 2026

世界トップデザインスクール（RCA、Parsons、RISD）の2026年カリキュラムを分析・統合した、次世代デザイン教育の包括的カリキュラムです。

## カリキュラム構成

| # | 書名 | テーマ | 影響元 |
|---|------|--------|--------|
| 1 | デザイン思考の基礎 | 基礎的なデザイン思考とリサーチ手法 | 共通基盤 |
| 2 | デザイン・フューチャーズ | 未来予測とスペキュラティブデザイン | RCA |
| 3 | 社会変革デザイン | 包摂的デザインと都市生態学 | Parsons |
| 4 | クリティカル・メイキング | 物質性とテクノロジーの融合 | RISD |
| 5 | AIパートナーシップデザイン | 生成AIとの協働 | 2026トレンド |
| 6 | サステナブルデザイン | 循環型経済とリジェネラティブ | 2026トレンド |
| 7 | デザイン戦略とリーダーシップ | 経営・組織・実践 | 統合 |

## コンテンツ統計

- 7冊の本、35章
- 100以上の概念を含む学習グラフ
- 用語集（50以上の用語）
- 参考文献（40文献）

## 2026年の3大トレンド

1. **Generative AI as a Partner** - AIを協働パートナーとして全工程に統合
2. **Sustainability Standard** - サステナビリティが必須要件化
3. **Flipped Studio** - 反転スタジオモデルによる効率化
