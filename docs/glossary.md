# 用語集

本カリキュラムで使用される主要用語の定義集です。ISO 11179準拠で、簡潔かつ明確な定義を提供します。

---

## あ行

**アクセシビリティ (Accessibility)**
: 年齢、障害、状況に関わらず、すべての人が製品やサービスを利用できるようにするデザインの性質。

**アルゴリズムバイアス (Algorithmic Bias)**
: AIシステムの学習データや設計に起因する、特定の集団に対する体系的な偏見や不公平な結果。

**インターセクショナリティ (Intersectionality)**
: 人種、ジェンダー、階級、障害などの社会的カテゴリが交差し、複合的な差別や特権を生み出すという概念。

**インタラクティブインスタレーション (Interactive Installation)**
: 鑑賞者の行動や入力に応じてリアルタイムに変化する、空間的なアート・デザイン作品。

**エスノグラフィー (Ethnography)**
: 対象者の生活環境に入り込み、観察と参与を通じて文化的文脈を深く理解するリサーチ手法。

**エンパシーマッピング (Empathy Mapping)**
: ユーザーが「考えること」「感じること」「言うこと」「行うこと」を4象限で可視化するリサーチツール。

## か行

**カーボンフットプリント (Carbon Footprint)**
: 製品やサービスのライフサイクル全体で排出される温室効果ガスの総量をCO2換算で表した指標。

**クラフトマンシップ (Craftsmanship)**
: 素材の特性を深く理解し、熟練した技術と注意深さをもって制作する能力と姿勢。

**クリティカルデザイン (Critical Design)**
: 商業的な問題解決ではなく、社会的・文化的な前提を問い直し、議論を喚起することを目的としたデザインアプローチ。

**クリティカルメイキング (Critical Making)**
: 手を動かす制作行為（Making）と批判的思考（Critical Thinking）を統合し、作ることを通じて考えるアプローチ。

**クレイドル・トゥ・クレイドル (Cradle to Cradle)**
: 製品の素材が廃棄されることなく、生物サイクルまたは技術サイクルを通じて永続的に循環するデザイン哲学。

**コデザイン (Co-design)**
: デザイナーとユーザーが対等なパートナーとして、デザインプロセスの全段階で共同して創造する手法。

**コンテクスチュアルインクワイアリ (Contextual Inquiry)**
: ユーザーの実際の作業環境で、作業を観察しながら半構造化インタビューを行うリサーチ手法。

## さ行

**サーキュラーエコノミー (Circular Economy)**
: 資源の採取→製造→消費→廃棄の一方通行（リニアエコノミー）を脱却し、資源を循環させる経済モデル。

**サービスデザイン (Service Design)**
: サービスの全体的な体験を、ユーザー視点とプロバイダー視点の両方から設計・改善するデザイン分野。

**サービスブループリント (Service Blueprint)**
: サービスのフロントステージ（顧客接点）とバックステージ（裏方プロセス）を含む全体像を可視化する図。

**サステナブルデザイン (Sustainable Design)**
: 環境、社会、経済の持続可能性を考慮し、負の影響を最小化するデザインアプローチ。

**シナリオプランニング (Scenario Planning)**
: 複数の異なる未来シナリオを体系的に構築し、不確実性に対する戦略的準備を行う手法。

**シビックテクノロジー (Civic Technology)**
: 市民参加、政府の透明性、公共サービスの改善を目的としたテクノロジーの設計・開発。

**システム思考 (Systems Thinking)**
: 個別の要素ではなく、要素間の関係性とフィードバックループに着目して全体を理解するアプローチ。

**スペキュラティブデザイン (Speculative Design)**
: 現実の製品開発ではなく、ありうる未来の可能性を提示し、社会的議論を触発するデザイン実践。

**スマートテキスタイル (Smart Textiles)**
: センサー、アクチュエータ、導電性繊維などを織り込み、環境の変化に応答する機能を持つ繊維素材。

## た行

**ダイエジェティック・プロトタイプ (Diegetic Prototype)**
: フィクションの物語世界内に存在する架空の製品やサービスを、あたかも実在するかのようにデザインしたプロトタイプ。

**タクティカルアーバニズム (Tactical Urbanism)**
: 短期的・低コストの介入を通じて、都市空間の長期的な変化を促す草の根的な都市計画アプローチ。

**タッチポイントデザイン (Touchpoint Design)**
: サービスにおける顧客との接点（物理的・デジタル・人的）を意図的に設計し、一貫した体験を構築すること。

**タンジブルインターフェース (Tangible Interface)**
: 物理的な物体を介してデジタル情報を操作する、身体性を伴うインタラクションの設計。

**チェインオブソート (Chain-of-Thought)**
: AIに段階的な推論過程を明示的に生成させることで、複雑な問題の回答精度を向上させるプロンプト技法。

**デザインオプス (DesignOps)**
: デザインチームの効率性、品質、影響力を最大化するためのプロセス、ツール、組織構造の最適化。

**デザインジャスティス (Design Justice)**
: デザインプロセスにおける権力構造に着目し、最も周縁化された人々を中心に据えるデザインの枠組み。

**デザインフィクション (Design Fiction)**
: SFの物語構造とデザインの方法論を融合し、ありうる未来の製品・サービス・社会をプロトタイプする手法。

**デジタルファブリケーション (Digital Fabrication)**
: 3Dプリンティング、レーザーカッティング、CNC加工など、デジタルデータから物理的なオブジェクトを製造する技術群。

**トランジションデザイン (Transition Design)**
: 社会の大規模な持続可能性への移行（トランジション）を、長期的視点でデザインする分野。カーネギーメロン大学が提唱。

## な行

**ナッジ理論 (Nudge Theory)**
: 選択肢の提示方法を工夫することで、人々の行動を強制なく望ましい方向に誘導する行動経済学の概念。

## は行

**バイオデザイン (Bio Design)**
: 生物学的プロセスや生物素材をデザインの核心に据え、自然の仕組みを活用した製品やシステムを創造する分野。

**バイオマテリアル (Biomaterial)**
: 生物由来または生物学的プロセスで生成される素材。菌糸体、藻類、セルロースなどを含む。

**バイオミミクリー (Biomimicry)**
: 自然界の形態、プロセス、システムを模倣し、人間の設計課題に対する持続可能な解決策を導く手法。

**バックキャスティング (Backcasting)**
: 望ましい未来の状態を先に定義し、そこから現在に遡って必要なステップを逆算する計画手法。

**パラメトリックデザイン (Parametric Design)**
: パラメータ（変数）とルール（アルゴリズム）によって形態を生成・制御するコンピュテーショナルデザイン手法。

**ヒューマンインザループ (Human-in-the-Loop)**
: AIシステムの判断プロセスに人間が介在し、監視・修正・承認を行う設計パターン。

**フィジカルコンピューティング (Physical Computing)**
: マイクロコントローラ、センサー、アクチュエータを用いて、物理世界とデジタル世界を接続するデザイン実践。

**フューチャーズ・コーン (Futures Cone)**
: 現在から未来に向かって広がる円錐形のモデルで、Probable（蓋然的）、Plausible（もっともらしい）、Possible（可能な）、Preferable（望ましい）未来を区別する。

**プラネタリーバウンダリー (Planetary Boundaries)**
: 人類が安全に活動できる地球システムの限界を定義する9つの境界条件（気候変動、生物多様性損失など）。

**プレイスメイキング (Placemaking)**
: コミュニティの資産やニーズに基づいて、公共空間を活性化し、人々のつながりを促進するデザインアプローチ。

**プロンプトエンジニアリング (Prompt Engineering)**
: 生成AIから望ましい出力を得るために、入力指示（プロンプト）を体系的に設計・最適化する技術。

## ま行

**マテリアルパスポート (Material Passport)**
: 製品に使用されている素材の組成、出所、リサイクル可能性を記録したデジタル文書。

**マルチモーダルAI (Multimodal AI)**
: テキスト、画像、音声、動画など複数の入出力モダリティを統合的に処理できるAIシステム。

## ら行

**ライフサイクルアセスメント (Life Cycle Assessment / LCA)**
: 製品・サービスの原材料採取から廃棄までの全段階における環境負荷を定量的に評価する手法。

**リジェネラティブデザイン (Regenerative Design)**
: 環境への負荷を最小化する（サステナブル）にとどまらず、生態系を積極的に回復・再生させるデザインアプローチ。

**レバレッジポイント (Leverage Points)**
: システムの中で小さな変化が大きな影響を生み出せる介入点。ドネラ・メドウズが12のレバレッジポイントを体系化。

## わ行

**ウィキッドプロブレム (Wicked Problem)**
: 明確な定義や唯一の正解が存在せず、多くのステークホルダーの価値観が絡み合う複雑な社会問題。

## アルファベット

**STEEPV分析 (STEEPV Analysis)**
: Social（社会）、Technology（技術）、Economic（経済）、Environment（環境）、Political（政治）、Values（価値観）の6軸で環境を分析するフレームワーク。

**2x2シナリオマトリクス (2x2 Scenario Matrix)**
: 2つの不確実性軸を直交させ、4つの異なる未来シナリオを生成するシナリオプランニング手法。
